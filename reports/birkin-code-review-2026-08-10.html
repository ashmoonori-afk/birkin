7. 잔여 위험과 비차단 항목

명시적 검증 공백

  • 실 credentialed egress send와 live model call은 정책상 실행하지 않았다.
  • live Codex child는 binary 부재로 argv 구성만 검증했다.
  • Win32 mapped/UNC는 차단했으나 POSIX mounted network filesystem 분류는 별도 구현이 아니다.
  • bandit/pip-audit가 환경에 없어 별도 static security scanner는 실행 불가했다.

기존 debt·전달 제약

  • repo 전체 basedpyright recommended mode에는 기존 대규모 typing debt가 있다; 본 변경 귀속 scope는 0/0/0이다.
  • uvx ruff 최신 버전과 project uv run ruff 버전 차이가 있다; 판정은 project toolchain 기준이다.
  • docs/DECISIONS.md의 duplicate ADR-050은 기존 문제로 이번 범위에서 삭제하지 않았다.
  • 보고서 commit은 자기 SHA를 본문에 포함할 수 없어 최종 답변의 remote SHA 검증으로 보완한다.
