# Landing / Marketing Copy

Write copy that prioritizes clarity and conversion over pretty phrasing.

## When to Use

- The user needs landing-page sections, ad copy, or an outbound message.

## When NOT to Use

- Strategy or analysis work (use a strategy/analysis approach instead).

## Always establish first

`target customer`, `problem`, `offer`, `proof`, `channel`, `CTA`. If any are
unknown, ask or state an explicit assumption — never invent proof, numbers, or
testimonials.

## Procedure

1. Lead with the customer's problem in their words.
2. State the offer and the single clearest benefit.
3. Back claims with real proof only; if there is none, drop the claim.
4. One primary **CTA**, unambiguous and low-friction.
5. Cut adjectives that don't change meaning.

## Output

- Headline, subhead, 3 benefit bullets (benefit → reason), and one CTA line.
  Keep it tight; mark any assumptions and missing proof explicitly.
