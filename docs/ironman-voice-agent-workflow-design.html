03 · code contracts

실제 파일과 책임

birkin/voice/wake.py

박수 impulse와 정규화된 phrase를 동시에 요구한다. cooldown clock은 주입 가능하며 raw audio를 보존하지 않는다.

birkin/voice/openai_voice.py

OpenAISTT와 OpenAITTS. SDK client seam으로 실제 request shape를 fake endpoint에서 검증한다.

birkin/voice/config.py

병합된 voice 설정을 typed defaults로 파싱한다. 명시한 CLI flag가 설정값보다 우선한다.

birkin/voice/controller.py

한 번의 wake·명령 수집·Gateway route·foreground/background delivery를 CLI에서 분리해 조정한다.

birkin/gateway/channels/local_http.py

1 MB JSON cap, 2초 body-read timeout, complete/string field를 강제하고 http|voice만 허용한다. telegram spoof는 400이다.

birkin/background.py

bounded daemon queue/backpressure와 deadlock-safe shutdown을 소유한다. ordered/atomic receipt 모델은 birkin/background_receipts.py로 분리했다.

04 · trust boundary

Wake phrase는 인증이 아니다

Routing only

박수와 phrase는 listening state만 연다. 명령 권한이나 approval을 만들지 않는다.

Gateway preserved

GatewayClient는 credential/query가 없는 loopback HTTP /message만 허용하고 기존 Gateway.handle()로 전달한다. BIRKIN_HTTP_TOKEN도 그 경계로만 전달된다.

Approval preserved

approved_work는 trusted Telegram workflow에만 설정된다. destructive voice QA는 두 flag가 false임을 확인했다.

05 · operator commands

실행 명령

결정적 fixture 모드

uv run birkin voice --once \
  --audio tests/fixtures/voice/clap_then_phrase.wav \
  --transcript "Daddy is home" \
  --command "status"

GPT STT + Gateway + TTS

uv run birkin voice --once \
  --audio wake.wav \
  --command-audio command.wav \
  --gateway-url http://127.0.0.1:8788/message \
  --tts-output reply.pcm --no-playback

기본 마이크

OPENAI_API_KEY=... uv run birkin voice --once \
  --gateway-url http://127.0.0.1:8788/message

Background receipt

uv run birkin voice --once ... \
  --background \
  --receipt-dir ~/.birkin/voice/jobs
